# Fonts

All fonts are bundled with the app (so it works offline) and are licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org). The variable-weight Latin files come from
[Fontsource](https://fontsource.org) (`@fontsource-variable/*`).

| File | Font | By | Used in |
|---|---|---|---|
| font-fraunces.woff2 | Fraunces | Undercase Type, Phaedra Charles, Flavia Zimbardi | Editorial (headings) |
| font-figtree.woff2 | Figtree | Erik Kennedy | Editorial (text and numbers) |
| font-inter.woff2 | Inter | Rasmus Andersson / The Inter Project Authors | Modern |
| font-source-serif.woff2 | Source Serif 4 | Frank Grießhammer / Adobe | Classic (headings) |
| font-source-sans.woff2 | Source Sans 3 | Paul D. Hunt / Adobe | Classic (text and numbers) |
| font-nunito.woff2 | Nunito | Vernon Adams, Cyreal, Jacques Le Bailly | Rounded |
| font-manrope.woff2 | Manrope | Mikhail Sharanda | Minimal |

Numbers always use lining, tabular figures (the same height and width), whichever pairing is chosen.
