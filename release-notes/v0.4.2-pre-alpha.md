> ⚠️ **Pre-alpha.** It works, but expect rough edges and changes. Please report problems under **Issues**, ideally with your **Activity log** (Settings → Activity log → Share log).

## 🐞 Fixed in 0.4.2
- **iPhone: model downloads stopped with "bad URL"** right after Hugging Face handed the download to its download server (`us.aws.cdn.hf.co`).
  - The app now follows each hand-off itself, one step at a time.
  - It cleans up any characters iOS won't accept in the address first, the same way a browser does.
  - The download link no longer asks for `?download=true`, which adds extra text to the download server's address.
  - Your Hugging Face token still only ever goes to Hugging Face.
- **Fresh model list.** The list saved by 0.4.1 is thrown away, so the newer ranking rules apply straight away.
- Download errors no longer say "1 MB" when nothing was downloaded.

## 🔍 Better logging
- Each download step now shows in the Activity log:
  - the address it went to: server, file, and the *names* of the address parts (the secret signature values are hidden);
  - whether any characters had to be fixed.

## 📥 Install
Same as before: install `Nourish-unsigned.ipa` (LiveContainer, AltStore or Sideloadly) or `Nourish.apk`. Your plan and settings are kept.
