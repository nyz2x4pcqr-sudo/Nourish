## 🧠 Qwen3.5-2B is now the recommended model on iPhones like yours
Nourish's own plan code ran both models on the same meal-plan request (3 days each, on a simulated iPhone):

| | Qwen3.5-2B (1.2 GB) | LFM2.5-2.6B (1.6 GB) |
|---|---|---|
| Time for 3 days | **1,445 s** | 1,704 s |
| Junk ingredient lines | 0% | 0% |

Qwen was about 15% faster and needs 0.4 GB less memory, so it's now marked **Recommended** on phones like the iPhone 16 Pro. The simulated phone used only its processor, so real iPhones are faster for both models. The model list is rebuilt once so the change shows straight away.

Everything from 0.4.5 is included: cleaner plans, plans that survive interruptions, the merged grocery list and the header fix.

## 📥 Install
Same as before: install `Nourish-unsigned.ipa` (LiveContainer, AltStore or Sideloadly) or `Nourish.apk`. Your plan and settings are kept.
