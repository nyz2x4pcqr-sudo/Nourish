## 🐞 iPhone downloads stuck on "waiting for an internet connection"
In 0.4.3 some iPhones (for example, running Nourish inside LiveContainer) could reach huggingface.co but got no data from Hugging Face's download server. Now:
- **The real error is shown.** The download no longer waits silently for a connection. iOS's actual error, with its full details, goes into the Activity log.
- **Automatic check.** When a download gets no data, Nourish checks the connection and writes the results to the Activity log:
  - which network you're on, Low Data Mode, VPN and proxy;
  - whether your phone can look up the download server's address (ad blockers and DNS filters show up here);
  - whether a plain request to the download server works.
- **Step-by-step download.** Nourish then downloads the model in 16 MB pieces, using the same kind of short requests that already work with huggingface.co.
  - Each piece is saved straight to storage.
  - A failed piece is tried again up to 5 times.
  - Tapping **Download** later continues from the last saved piece.
- **Check download connection** (Settings → Activity log) runs the same check whenever you like.
- The Activity log now records whether Nourish seems to be running inside LiveContainer.

**Keep Nourish open while a model downloads.** The screen stays on by itself during a download.

## ✅ Tested
On a simulated iPhone, the automatic tests:
1. run the download check;
2. download **LiquidAI LFM2.5-230M** in 16 MB pieces, and check the saved file against Hugging Face's listed size to the byte;
3. load it into the AI engine and have it answer;
4. download a second model normally, stop it partway, and continue it;
5. make a full 7-day meal plan on the phone.

## 📥 Install
Same as before: install `Nourish-unsigned.ipa` (LiveContainer, AltStore or Sideloadly) or `Nourish.apk`. Your plan and settings are kept.
