> ⚠️ **Pre-alpha.** It works, but expect rough edges and changes. Please report problems under **Issues**. The new **Activity log** makes that easy.

## 🐞 Fixed in 0.4.1
- **Model downloads failed with "HTTP 302"** on iPhone. Hugging Face hands downloads to its own download servers, and the app refused that hand-off. It now follows Hugging Face's redirects. They must stay secure (https), and your Hugging Face token is never sent to them. Android had the same check and gets the same fix.
- The automated tests now download a real model from Hugging Face *through the app itself*, on both iPhone and Android, so this can't slip through again.

## ✨ New
- **Activity log** (Settings → Activity log) shows what Nourish is doing, step by step:
  - your phone's specs and the memory budget for models;
  - every request to Hugging Face and its answer;
  - which models were kept or skipped, and why;
  - each download step, including where it was redirected, speed and errors;
  - model loading and generation times, plan days, chat and any errors.
  - Tap **Share log** or **Copy log** to send it. API keys and tokens are never included. **Detailed logging** is on by default.
- **The model list is always built live** on your phone from Hugging Face. There's no built-in list any more. If Hugging Face can't be reached, the app says so and offers **Retry**.

## 📥 Install
Same as 0.4.0: install `Nourish-unsigned.ipa` (LiveContainer, AltStore or Sideloadly) or `Nourish.apk`. Your plan and settings are kept.
